LICENCES

Composants tiers

Miarina Media est distribué gratuitement par MIARINA. Il s’appuie sur les composants suivants, sous leurs propres licences.

Outils inclus dans l’installateur (Windows)

Depuis la version 0.1.1, ils sont livrés avec l’installateur, dans le dossier tools de l’application, avec leurs textes de licence. Chaque fichier est pris dans la publication officielle et vérifié avec une empreinte SHA-256 fixée dans l’application. S’ils manquent, l’application propose de les télécharger, avec la même vérification.

  • yt-dlp 2026.08.19 — Unlicense (domaine public). L’exécutable contient un environnement Python et des bibliothèques sous leurs propres licences. Source : github.com/yt-dlp/yt-dlp.
  • FFmpeg n8.1.2, build « LGPL shared » de BtbN — GNU LGPL 3.0 ou ultérieure. Utilisé comme programme séparé. Binaires et sources correspondantes : github.com/BtbN/FFmpeg-Builds ; projet : ffmpeg.org. Les textes de la LGPL 3.0 et de la GPL 3.0 sont fournis dans le dossier tools.
  • QuickJS-NG 0.17.0 — licence MIT. Moteur JavaScript utilisé par yt-dlp pour certains sites (YouTube). Source : github.com/quickjs-ng/quickjs.

Polices et icônes (application et site)

  • Manrope — SIL Open Font License 1.1.
  • JetBrains Mono — SIL Open Font License 1.1.
  • Material Symbols Rounded (Google) — Apache License 2.0. Ce site en utilise un sous-ensemble.

Principales bibliothèques

Tauri, Rust (tokio, reqwest, rustls), SQLite (domaine public), React, Zustand, TanStack Virtual, Tailwind CSS, sous licences MIT, Apache 2.0, ISC ou BSD. L’inventaire complet des dépendances et de leurs notices sera publié avec la première version stable.
