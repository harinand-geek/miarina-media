Miarina Media - third-party tools shipped in this folder
=========================================================

Miarina Media runs these programs as separate processes. They are not
modified and not linked with Miarina Media. Each file was taken from the
official release below and checked against a pinned SHA-256 digest before
being packaged.

You may replace the FFmpeg DLLs in tools/ffmpeg/ with your own compatible
build of the same FFmpeg version, as the LGPL allows. Note that Miarina Media
only uses the folder whose name matches the pinned digest.
