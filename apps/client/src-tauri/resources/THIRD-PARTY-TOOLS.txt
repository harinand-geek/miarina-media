Miarina Media - third-party tools shipped in this folder
=========================================================

Miarina Media runs yt-dlp, FFmpeg and QuickJS-NG as separate processes;
the video player loads libVLC at run time (dynamic loading, nothing is linked
at build time). None of them is modified. Each file was taken from the
official release below and checked against a pinned SHA-256 digest before
being packaged.

You may replace the FFmpeg DLLs in tools/ffmpeg/, or the libVLC files in
tools/libvlc/, with your own compatible build of the same version, as the
LGPL allows. Note that Miarina Media
only uses the folder whose name matches the pinned digest.
