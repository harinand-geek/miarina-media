Desktop notes Tabs sit in the title bar (Chromium-style strip, 220 px, min 120 px). Active tab = surface #182530 joined to the toolbar. A teal count badge on a tab means media was detected there. Address bar: 34 px pill, host in text color, path muted, mono. Media chip “3 media” appears inside the bar as soon as detection finishes; it opens D2 just like the floating button. Star in the bar toggles favorite (Ctrl+D); filled amber when saved. Favorites bar under the toolbar is optional (Settings → Browser → Show favorites bar). Floating button: bottom-right of the web viewport, 24 px inset, 52 px high. Left part downloads the default format of all detected media; chevron opens D2. D2 is anchored above the floating button (440 px wide, radius 14), not centred. Esc or scrim closes. Shortcuts: Ctrl+T new tab · Ctrl+W close · Ctrl+L focus address · Ctrl+H history · Ctrl+D favorite · Ctrl+Shift+S open format sheet.

Android notes Bottom navigation becomes Home · Browser · Downloads · Library. Browser takes the slot Settings used to occupy. Settings moves to a gear icon in the Home top app bar (dashed outline in M5 marks the change) and to the ⋮ menu in the browser. Same Settings screen, opened as a full page with a back arrow. Browser address bar is on top, 44 dp pill; the 3 dp teal line under it is page-load progress. Tab counter square opens M2. Browser bar at the bottom: back, forward, home, history, Miarina (exits to the app). Floating button is centred above the bottom bar. Tap = M3 for the first media; long-press = download default format immediately. M3 reuses the existing analysis sheet: media chips at the top switch between the detected items on the page. M4 is reached from ⋮ → History. Tabs switch between History and Favorites; the favourite row at the top doubles as the browser’s new-tab shortcuts.
