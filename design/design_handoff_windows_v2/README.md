# Handoff : Miarina Media — refonte Windows v2

## Vue d'ensemble
Refonte UI/UX du client Windows de Miarina Media (Tauri 2 + React, `apps/client`) répondant au cahier des charges **CDC-MIARINA-001** (`docs/CAHIER-DES-CHARGES-AMELIORATIONS-MIARINA.md`). Toutes les fonctions actuelles sont conservées ; la refonte ajoute : navigation en deux espaces, bibliothèque musicale, écran « En lecture » + file, mini-lecteur, lecteur vidéo natif (pistes/sous-titres), égaliseur/vitesse/minuteur, éditeur de tags et pochettes, mises à jour signées, torrents avec partage maîtrisé, états vide/erreur/hors-ligne, FR/EN, thèmes clair/sombre, nouveau logo 4d.

## À propos des fichiers
Les fichiers de ce dossier sont des **références de design en HTML** (prototype cliquable), **pas du code de production**. La tâche est de **recréer ces écrans dans `apps/client`** avec ses patterns existants : React 19, Tailwind 4 (`src/styles/theme.css`, tokens `--mm-*`), stores Zustand (`src/stores/*`), composants `src/components/*` (Button, Controls, Icon, Menu, Overlay, ProgressBar, ToastHost…), écrans `src/features/*`. Ne pas embarquer le HTML.
Ouvrir `Miarina Media Windows v2.dc.html` dans un navigateur (avec `support.js` à côté). La barre au-dessus de la fenêtre bascule Langue / Thème / Navigation / Scénario (normal, vide, hors ligne, aucun média).

## Fidélité
**Haute fidélité.** Couleurs, typo, espacements, rayons et comportements sont définitifs. Reproduire au pixel près en réutilisant les composants existants. Les zones hachurées sont des placeholders (miniatures, pochettes, surface vidéo, page web).

## Règles d'interaction
- Teal = télécharger / sélectionner / progresser / focus. **Corail = lire** (play, position de lecture, mini-lecteur, En lecture, égaliseur). Un seul bouton plein de chaque accent par vue.
- Hover 80 ms ; toggles/chips 150 ms ; changement d'écran fondu + montée 8 px 160 ms ; dialogues 220 ms scale .98→1 ; progression interpolée 900 ms linéaire. Reduce motion / Eco : fondus 120 ms.
- Raccourcis : Ctrl K recherche, Ctrl V coller+analyser, Ctrl B sidebar, Ctrl P pause tout, Espace lecture, ←/→ ±10 s, F plein écran, Échap, Ctrl T/W onglets.
- Focus : outline 2 px teal offset 2 (`:focus-visible`). Cibles ≥ 32 px.
- Toutes les chaînes passent par un catalogue FR/EN (UX-01) ; le prototype contient les deux langues (objet `t` + fonction `L(fr, en)` dans la classe).

## État (correspondance stores)
`ui` : screen, space ('dl'|'play'), sidebarCollapsed, dialog, tagEditor. `player` (nouveau, contrat COM-01) : kind, mediaId, state, position, duration, queue, shuffle, repeat, rate, eq {enabled, preset, bands}, sleepTimer, audioTrack, subtitle, subtitleDelay. `library` : view, kind, query, favorites, playlists, folders (scan state, availability). `downloads` : tasks (state: queued|downloading|converting|paused|error|done). `updates` : phase (none|available|downloading|ready|installing), channel. `torrents` : session, rows, limits, ratio/time targets.
