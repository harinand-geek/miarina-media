- Taille minimale 16 px ; logotype ≥ 120 px de large.
- Zone de protection = 4 unités sur 32 (12,5 %).
- Ne pas inverser corail/teal, déformer, pivoter, ni poser le glyphe couleur sans tuile sur un fond coloré.
- Typo : Manrope (UI/marque), JetBrains Mono (valeurs machine).
